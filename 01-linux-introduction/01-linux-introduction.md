# Introduction to Linux

## What is Linux?
Linux is a free and open-source operating system. It manages computer hardware and software and provides an environment to run applications.

## Examples of Linux Distributions
- Ubuntu
- Fedora
- Debian
- Red Hat Enterprise Linux (RHEL)

## Main Features
- Free and open-source
- Multiuser operating system
- Multitasking support
- Secure and stable
- Powerful command-line interface

## Linux Uses
- Web servers
- Cloud computing
- Cybersecurity
- Software development
- Supercomputers

## Linux Architecture
1. Hardware – Physical components of the computer
2. Kernel – Manages hardware, memory, processes, and devices
3. Shell – Accepts commands from the user
4. Applications – Programs used to perform tasks

## Example
When you type `ls` in the terminal, Linux displays the files and folders in the current directory.

## Conclusion
Linux is widely used in servers, cloud platforms, networking, and cybersecurity because of its flexibility, stability, and open-source nature.
